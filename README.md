# The MorpheFit — Static Mobile Website

Phone-first static gym website in the black/electric-blue/cyan visual style requested.

## Files
- `index.html` — complete static website
- `assets/morphefit-gym.jpg` — supplied MorpheFit poster used as the initial gym visual

## Edit later
- Replace gallery placeholders with your real gym photos.
- Replace the video placeholder with your real videos/embeds.
- Add actual membership prices in the plan cards.
- Add verified member reviews.
- Update hours/social links if needed.

## Run
Open `index.html` in Chrome, or use VS Code Live Server.
